requirements.txt - has list of requirements

use pipenv
    - no longer need to manually activiate virtual env each time visual studio code is restarted
    - tracks dependencies with pipfile and pipfile.lock (pipfile replaces requirements.txt)
    - commands
        1. pipenv install (creates a pipfile)
        2. **doesn't work** - pipenv install -r requirements.txt (installs all the packages in txt in virtual evn)
        3. pipenv install requests==2.32.5 beautifulsoup4==4.14.2 playwright==1.55.0 aio-pika==9.5.7
            -installs in virtual env and updates pipfile and pipfile.lock
        4. pipenv run playwright install (to get the browser binaries - downloads the required browser engines)
    -activate the virtual env
        - pipenv shell or pipenv run python your_script.py
    - recreate env from lock file
        - pipenv sync
    - check installed packages
        - pipenv graph
    - uninstall packages (removes package from virtual env and pipfile and pipfile.lock)
        - pipenv uninstall <package-name>
